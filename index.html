What Jarvis does that most agents don’t.

Five things that change how a day with an AI agent feels.

1 / 5

It remembers you.

Tell Jarvis your name, your stack, how you like commits written. It saves those facts and brings them into every new session, so you stop repeating yourself.

Every fact is a plain line you can read, edit or delete with /memory.

Loaded into every session. Stored on your machine.
2 / 5

It learns from its own work.

When Jarvis solves something tricky, it writes down a short lesson: the kind of task, and what actually worked. Next time a similar task shows up, the lesson is already in front of it, so it skips the dead ends.

Lessons that keep proving useful are kept. The rest are pruned.

Lessonsrecalled for this task
Lockfile conflict during rebase
Regenerate the lockfile with the package manager instead of merging it by hand.

Wait for the network to go idle instead of a fixed timeout.

pricingNew lesson
3 / 5

It checks the web, then checks again.

Jarvis can search, open pages and read docs. For questions of fact it runs a verified search: it reads several independent sources, compares what they claim, and tells you how well they agree.

Three steps to your first task.

You need Python 3.10 or newer. Jarvis installs into its own environment and adds one command: jarvis.

  1. 1

    Get Python

    Skip this if python3 --version already shows 3.10 or newer.

    $brew install python@3.11
  2. 2

    Run the installer

    Run it again any time to update.

    $curl -fsSL https://raw.githubusercontent.com/PrajsRamteke/harness-agent/main/scripts/install | bash
  3. 3

    Open a project and start

    Open a new terminal in any project folder.

    $jarvis
  1. 1

    >jarvis
